# BacklogBurn

Static launch prototype.

## Main pages
- index.html — game backlog burn-rate calculator
- games-per-year.html
- cost-per-hour.html
- gaming-time.html
- methodology.html
- about/privacy/terms

## Before launch
1. Choose and buy a real domain.
2. Replace `https://example.com/` canonical/sitemap URLs.
3. Upload to a GitHub repository.
4. Deploy repository with Cloudflare Pages.
5. Test mobile + desktop.
6. Add Google Search Console.
7. Do not enable ad code until privacy/consent requirements are handled and the site has enough useful content.
